# 📊 Fundamental Booster – Microsoft Excel Practice Project

## 📌 Project Overview

**Fundamental Booster** is a Microsoft Excel practice project designed to strengthen fundamental Excel skills through practical datasets and formula-based exercises. It includes sales analysis, student performance evaluation, and employee data management using commonly used Excel functions.

The project helps learners understand how Excel formulas work with real-world-style data and how spreadsheet functions can simplify calculations, data extraction, and analysis.

## 🎯 Project Objectives

- Strengthen fundamental Microsoft Excel skills.
- Practice logical, text, date, and mathematical functions.
- Understand relative and absolute cell references.
- Perform data lookup and conditional analysis.
- Improve accuracy and efficiency in spreadsheet calculations.
- Develop practical data-handling and analytical skills.

## 📂 Project Worksheets

### 1. 💰 Sales Data
Contains sales records with product, region, salesperson, amount, date, and discount information.

**Key concepts:**
- Conditional discount calculations using `IF`
- Discount eligibility using logical functions
- Date and age calculations
- Sales data lookup and analysis
- Dynamic ranges and reference-based formulas

### 2. 🎓 Student Data
Contains student records with subject-wise marks, enrollment dates, and calculated results.

**Key concepts:**
- Total marks and percentage calculations
- Grade classification using `IF`
- Relative and absolute cell references
- Logical conditions using `AND`
- Identifying students who score above a specified threshold

### 3. 👨‍💼 Employee Data
Contains employee records, including employee IDs, names, departments, salaries, joining dates, and decimal amounts.

**Key concepts:**
- Extracting text using `LEFT`
- Changing text case using `UPPER` and `LOWER`
- Working with employee information
- Handling decimal values
- Applying formulas to multiple records

## 🛠️ Tools and Technologies

## 📚 Excel Functions Practiced

| Function | Purpose |
|---|---|
| `IF` | Apply conditional logic |
| `AND` / `OR` | Test multiple conditions |
| `SUM` | Calculate totals |
| `LEFT` | Extract characters from text |
| `UPPER` / `LOWER` | Change text case |
| `YEARFRAC` | Calculate the fraction of a year between dates |
| `INT` | Return the integer portion of a number |
| `INDEX` / `MATCH` | Retrieve values using lookup criteria |
| `XLOOKUP` | Search for matching data |
| `INDIRECT` | Create references from text |
| `OFFSET` | Create a reference relative to a starting cell |
| `FILTER` | Extract records that meet specified conditions |

*The functions listed represent the skills practiced or targeted in the project; not every function is necessarily used in every worksheet.*

## 🚀 How to Use

1. Download or clone this repository.
2. Open `Fundamental Booster.xlsx` in Microsoft Excel.
3. Explore the Sales Data, Student Data, and Employee Data worksheets.
4. Select cells containing formulas to understand how calculations work.
5. Modify sample values to observe how formula results change.
6. Practice creating additional formulas and analyzing the datasets.
